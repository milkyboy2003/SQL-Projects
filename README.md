Student Database — Relational Database Project

A PostgreSQL database project built as part of freeCodeCamp's **Relational Database Certification**. This project demonstrates the design, creation, and querying of a relational database via the Bash terminal using PostgreSQL.


 Project Overview

* Designed a normalized relational database schema to manage student records, courses, majors, and enrollment details.
* Wrote SQL scripts to create, alter, and establish relationships across multiple tables.
* Executed data manipulation and querying tasks directly within a Unix/Linux bash terminal environment.

---

 Skills & Technologies Demonstrated

* **Database Management System:** PostgreSQL
* **Querying & Manipulation:** SQL (DDL & DML commands including `CREATE`, `INSERT`, `SELECT`, `JOIN`, `ALTER`, `FOREIGN KEY`)
* **Database Design:** Relational Schema Architecture, Data Normalization, Entity-Relationship Mapping
* **Command Line Interface:** Bash Shell Navigation, Terminal-based Database Administration
